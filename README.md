# 🇮🇹 Italiano – אפליקציה ללימוד איטלקית לדוברי עברית

אפליקציה לטלפון, בנויה על מה שהמחקר מראה שבאמת עובד בלימוד שפה:
**שליפה מרווחת (FSRS)**, **הרבה איטלקית מובנת**, **דיבור עם משוב מתקן**, והסברים קצרים בעברית.

- 🧠 **תרגול יומי** – כל מילה חוזרת בדיוק כשאתם עומדים לשכוח. התרגילים מתקשים בהדרגה: זיהוי → הקשבה → השלמה → כתיבה → דיבור.
- 📚 **36 יחידות מ-A1 עד B2**: 16 יחידות בסיס (~350 מילים מוכנות) + 20 יחידות B1–B2 (דקדוק מוכן, המורה מכינה מילים לפי שכיחות – 30 בכל פעם, בלי הגבלה).
- 🎯 **מסלול אינטנסיבי ל-B2**: יעד זמן יומי, תוכנית 90 יום עם מעקב קצב (מילים/שעות/יחידה), הערכת רמה לפי השיחות, ורישום של האזנה חיצונית.
- 🗣️ **שיחות עם מורה AI** ב-11 מצבים אמיתיים (בית קפה, מלון, רכבת…), בקול או בהקלדה, עם תיקונים והסברים בעברית.
- 🎧 **סיפורים אישיים** שנכתבים מהמילים שלמדתם, עם תרגום בלחיצה, הקראה ותרגול חיקוי (shadowing).
- ✍️ **כתיבה יומית** עם תיקון ומשוב.
- ➕ **מילים לפי נושא** שמעניין אתכם.
- 📴 התרגול עובד גם **בלי אינטרנט** וגם **בלי AI**.

על המחקר וההחלטות: [RESEARCH.md](RESEARCH.md)

## 🚀 הפעלה ראשונה (פעם אחת, כ-15 דקות, מהמחשב)

### שלב 1: לפרסם את האפליקציה באינטרנט (חינם, GitHub Pages)
1. היכנסו ל-repo ב-GitHub: `https://github.com/yaakobiamir-code/Italian_app`
2. אם ה-repo **פרטי**: Settings ← General ← למטה "Danger Zone" ← **Change visibility** ← Public. (GitHub Pages חינם רק ל-repo ציבורי. אין בקוד שום מידע אישי או סודי.)
3. לחצו **Settings** ← בתפריט הצד **Pages**.
4. תחת **Build and deployment** ← Source: בחרו **Deploy from a branch**.
5. תחת Branch: בחרו את הענף **`claude/italian-learning-app-puclg2`** (או `main`, אם מיזגתם אליו), ותיקייה **`/ (root)`** ← **Save**.
6. חכו 1–3 דקות ורעננו את הדף. למעלה תופיע כתובת, בערך:
   **`https://yaakobiamir-code.github.io/Italian_app/`**

### שלב 2: להתקין בטלפון
- **אייפון:** פתחו את הכתובת ב-**Safari** ← כפתור השיתוף ⬆️ ← **"הוסף למסך הבית"**.
- **אנדרואיד:** פתחו ב-**Chrome** ← תפריט ⋮ ← **"התקן אפליקציה"** / "הוסף למסך הבית".

מעכשיו פותחים מהאייקון כמו כל אפליקציה. אפשר כבר להתחיל את התרגול היומי.

### שלב 3: להפעיל את מורה ה-AI (בשביל שיחות, סיפורים וכתיבה)
1. היכנסו ל-**console.anthropic.com** (או platform.claude.com) והירשמו.
2. **Billing** ← הוסיפו אמצעי תשלום וטענו את הסכום המינימלי (כ-5$). זה יספיק לחודשים רבים.
3. מומלץ: **Limits** ← הגדירו מגבלת הוצאה חודשית (למשל 3$) – כך אין הפתעות.
4. **API Keys** ← **Create Key** ← תנו שם ← **העתיקו את המפתח** (מתחיל ב-`sk-ant-`, מוצג פעם אחת בלבד).
5. באפליקציה בטלפון: **עוד ← הגדרות** ← הדביקו את המפתח ← **"שמירה ובדיקה"**. מופיע ✓? מוכן.

> 💡 הכי נוח: לשלוח את המפתח לעצמכם (למשל בוואטסאפ לעצמכם), להעתיק בטלפון, ואז **למחוק את ההודעה**.

💰 **עלות משוערת:** עם המודל המומלץ (Claude Haiku 5.5), שיחה של 20 הודעות עולה כחצי סנט. שימוש יומי רגיל ≈ **0.20–0.60$ לחודש**; במסלול אינטנסיבי (שעות ביום) ≈ **2–5$ לחודש**. מונה עלות בהגדרות.

### שלב 4 (מומלץ): קול איטלקי איכותי ותזכורת
- **אייפון:** הגדרות ← נגישות ← תוכן מדובר ← קולות ← איטלקית ← הורידו קול "משופר" (Alice/Federica). באפליקציה: הגדרות ← קול.
- **אנדרואיד:** הגדרות ← שפה וקלט ← המרת טקסט לדיבור ← Google ← התקנת נתוני קול ← איטלקית.
- **מקלדת איטלקית** בטלפון: נותנת à è ì ò ù והכתבה קולית באיטלקית.
- **תזכורת:** באפליקציה הגדרות ← תזכורת יומית ← "הוסף ליומן" ← פתחו את הקובץ.

## 🎯 יעד B2 – כמה זה לוקח באמת
ההערכות המקובלות (Cambridge, FSI): **כ-500–650 שעות** מאפס עד B2 באיטלקית.
| זמן ביום | אחרי 3 חודשים | B2 בערך אחרי |
|---|---|---|
| שעה | B1 | שנה וחצי |
| 2–3 שעות | B1+ | 5–7 חודשים |
| 6–7 שעות | **B2** | 3 חודשים |

באפליקציה: עוד ← הגדרות ← "זמן לימוד ביום" (או בפתיחה הראשונה). ביעד של שעה ומעלה נפתחת **תוכנית B2 ל-90 יום** עם תוכנית יומית מורחבת ומעקב קצב. רשימת פודקאסטים וסדרות לפי שלב: מסך הבית ← "מה להאזין?".

## 📅 שימוש יומי – גרסה בסיסית (15–25 דקות)

1. **פותחים את האפליקציה ← "תרגול יומי"** (7–10 דק'). עונים, ומנחשים גם כשלא בטוחים. אומרים כל מילה בקול.
2. **סיפור** (5–10 דק'): מאזינים בלי טקסט ← קוראים ולוחצים על מילים לא מוכרות ← מאזינים שוב ← מחקים משפטים עם 🎙️.
3. **שיחה** (5 דק'): בוחרים מצב ומדברים עם ג'וליה, לפחות 6 משפטים. בסוף 🏁 ← "הוסף את כל התיקונים לתרגול".
4. פעם-פעמיים בשבוע: **כתיבה יומית**, וקריאת הסבר הדקדוק של היחידה הבאה (לשונית "קורס").

**גרסה אינטנסיבית (2–6 שעות):** כמה שיעורי כרטיסיות ברצף · דקדוק היחידה · 2–3 סיפורים · 2–3 שיחות · כתיבה · שעה ומעלה של פודקאסטים/סדרות (רושמים באפליקציה) · מ-B1: 2–3 שיחות בשבוע עם אדם אמיתי. פירוט במדריך באפליקציה.

**כללי זהב:** כל יום (גם 5 דקות ביום עמוס) · לנחש לפני שמסתכלים · לדבר בקול · טעויות הן חלק מהלמידה.

**💾 גיבוי:** ההתקדמות נשמרת בטלפון. פעם בחודש: הגדרות ← "שמירת קובץ גיבוי". בטלפון חדש: "טעינת גיבוי".

## 🛠️ מידע טכני (למי שמעניין)
- אפליקציית ווב סטטית (HTML/CSS/JavaScript, בלי שלב build), PWA עם service worker לעבודה לא מקוונת.
- אלגוריתם חזרה: FSRS-4.5 (`js/srs.js`). תוכן הקורס: `js/data.js`. שכבת AI: `js/ai.js` (Claude API דרך ה-SDK הרשמי `@anthropic-ai/sdk` 1.3.0, מצורף ב-`vendor/`).
- ההתקדמות נשמרת ב-localStorage. המפתח נשמר רק במכשיר ונשלח רק ל-`api.anthropic.com`.
- הרצה מקומית: `python3 -m http.server` בתיקייה ופתיחת `http://localhost:8000`.
